# Evaluation

Starten des Backends: 
`cd backend`
`npm install`
`npm run dev`

Starten des Frontends:
`cd frontend`
`npm install`
`npm run start` oder `ng serve`

Hinweise: es wird node.js sowie Angular benötigt.

Für die Erstellung der Ground Truth: `http://localhost:4200/labels`
Für eine Ansicht der Analyse:  `http://localhost:4200` für eine Übersicht aller möglichen Videos.
